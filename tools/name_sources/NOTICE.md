# Name data sources and licences

The name lists in `phoney/data/name_data/` are built by `tools/build_name_data.py`
from the openly licensed datasets below, then filtered (script, characters,
length) and de-duplicated. No names were generated by a language model.

| Source | Used for | Licence |
|---|---|---|
| [Faker](https://github.com/joke2k/faker) 40.40.0, `faker/providers/person/*` | Given names and surnames for most locales | MIT (notice below) |
| [sigpwned/popular-names-by-country-dataset](https://github.com/sigpwned/popular-names-by-country-dataset) | Most popular given names and surnames per country | CC0 1.0 (public domain) |
| US Social Security Administration baby names 1880–2008, via [hadley/data-baby-names](https://github.com/hadley/data-baby-names) | `en_US` given names | US government work (public domain) |
| [smashew/NameDatabases](https://github.com/smashew/NameDatabases) | `en_US` and `en_GB` surnames | The Unlicense (public domain) |
| [shuheilocale/japanese-personal-name-dataset](https://github.com/shuheilocale/japanese-personal-name-dataset) | `ja_JP` given names (2 kanji spellings per reading) and surnames | MIT (notice below) |
| phoney's earlier name lists (`tools/name_sources/legacy/`) | Locales where those lists were sound | MIT (this project) |
